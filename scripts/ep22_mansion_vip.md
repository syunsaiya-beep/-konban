# 第22話「知らない番組の、スペイン風オムレツ」

チャンネル:ボソボソ親父のつぶやきキッチン
尺の目安:約3分 / 料理:じゃがいもの卵焼き(トルティージャ風)

## 使ってよい事実(収録前に最新情報で確認)
- 検索トレンドに「quien salio de la mansion vip 2」(マンション VIP 2、誰が出たか)が出た
- 関連報道:スペイン語圏の番組「La Mansión VIP」で、
  視聴者投票の状況と、リスクのある出演者に関する記事
- 番組の中身・出演者名は未確認。台本では触れない

## 台本

【オープニング / 画面:じゃがいもを洗う】
……こんばんは。親父です。
今日の検索ランキングにね、スペイン語のが、出てまして。

「キエン・サリオ・デ・ラ・マンション・ブイアイピー・ドス」……。

(間)

……合ってますかね。
言えてないと思います。

【中盤 / 画面:ニュース見出し】
どうやら、スペイン語のテレビ番組で、
「今日は誰が出ていくのか」と、
みんなが気にしてる、と。

投票で、決まるそうで。

私は、見たことがありません。
なので、中身は、語りません。

(ボソッと)
「知らないことは知らない」と言える親父で、
ありたいんです。

【調理 / 画面:手元】
でも、せっかくなので、
スペイン語圏っぽいものを作ります。

じゃがいもを薄切りにして、少ない油で、じっくり。
火が通ったら、溶き卵に、混ぜる。
フライパンに戻して、丸く、焼く。

(じゅうう、音)

ひっくり返すのが、緊張するんですよ。
お皿を、かぶせて……、せーの。

(間)

……よし。きれいに、いきました。

【クロージング】
あったかいうちに、いただきます。
じゃがいもと卵の、やさしい味。

番組の結果は、私には、わかりません。
けど、世界のどこかで、
今夜も誰かが、投票してるんだなぁと思うと、
ちょっと、おもしろいです。

……また、次回。

## 収録前チェック
- [ ] スペイン語の読み上げが不安なら、字幕で出して読み上げは省略してよい
- [ ] 番組を実際に見られれば、感想を足すと一番強くなる
- [ ] 「スペイン風オムレツ」は料理の説明。番組がスペインとは限らない点に注意(台本は「スペイン語圏」と表現)
