# 第1話「ゆれた夜の、ひとり台所」

チャンネル:ボソボソ親父のつぶやきキッチン
尺の目安:約3分 / 料理:缶詰とご飯の「ありもの雑炊」

## 使ってよい事実(収録前に最新情報で確認)
- 米国時間11/22夜、カリフォルニアで地震が2回あったと報じられた
- ロサンゼルス中心部付近でM4.4の地震の報道あり
- 被害の有無は台本では触れない(確認できていないため)

## 台本

【オープニング / 画面:薄暗い台所、鍋に水】
(ボソボソと)
……えー、こんばんは。親父です。
今日はね、アメリカのロサンゼルスの近くで、地震があったそうで。
マグニチュード4.4。ニュースで見ました。

(間)

……ケガした人がいないといいなぁ、と。それだけです。
ここで偉そうなことは言えません。

【中盤 / 画面:戸棚を開ける】
で、ですね。地震のニュースを見ると、
うちの台所は大丈夫かな、って、いつも思うんですよ。

ほら、見てください。
缶詰。ちょっとある。米。ある。
……乾物。味噌。

(小声で)
これが、ほんとのところ、我が家の「備え」です。
立派なもんじゃないです。

【調理 / 画面:手元】
今日は、この「ありもの」で雑炊をつくります。
ご飯を鍋に入れて、水を、ひたひたより少し多め。
サバ缶を汁ごと。ここ、汁を捨てないのがコツ。
味噌をちょっと溶いて、火にかけて……。

(煮える音を数秒そのまま)

……ガスを使うとき、火の元をね、
ちゃんと見ながらやるのが、一番大事。
火を使ってる間は、ここから離れない。

【クロージング】
……できました。
派手さはないです。でも、あったかいです。

食べ物が減ったら買い足す。使ったら補充する。
それだけで、いざというとき、ちょっと気が楽になる。

(間)

被害が大きくないことを、祈ってます。
いただきます。……また、次回。
