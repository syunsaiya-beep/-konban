# 第24話「聖夜の続編と、ローストチキンもどき」

チャンネル:ボソボソ親父のつぶやきキッチン
尺の目安:約3分 / 料理:フライパンで作る骨付きチキンの照り焼き

## 使ってよい事実(収録前に最新情報で確認)
- 検索トレンドに「violent night 2」が出た
- 関連報道:映画『Violent Night 2』の先行試写会パスのプレゼント告知記事
- 公開日・出演者・あらすじは未確認。台本では出さない
- 前作の内容も確認していないため、触れない

## 台本

【オープニング / 画面:鶏もも肉をキッチンペーパーで拭く】
……こんばんは。親父です。
映画の話です。『Violent Night 2』。続編が、あるそうで。

検索ランキングに出てました。
見出しを見ると、先行上映会の券が、当たる、と。

(ボソッと)
……私は、応募してません。
締め切りも、知りません。

【中盤 / 画面:タイトルを映す】
タイトルからして、クリスマスの映画なんでしょう。
ただ、私、どんな映画か、詳しくは、知りません。

だから、感想は、言えない。
言えるのは、一つだけ。

(間)

……クリスマスが近づくと、
鶏肉が、食べたくなる。
これは、映画と関係なく、毎年そうです。

【調理 / 画面:手元】
今日は、フライパンで、照り焼きチキン。
オーブンは、使いません。

鶏もも肉に、塩を軽く。
皮目から、中火で、じっくり焼く。
じっくり。……動かさない。

(じゅうじゅう、数秒)

焼き色がついたら、ひっくり返して、蓋。
最後に、醤油、みりん、砂糖を、まわしかける。
照りが、出るまで、煮つめる。

【クロージング】
……できました。
皮が、ぱりっと。たれが、つやつや。

映画を観に行く人も、家で待つ人も、
とりあえず、おなかが満たされてれば、
だいたいのことは、なんとかなる。

(小声で)
続編の感想は、観た人に聞いてください。
いただきます。……また、次回。
